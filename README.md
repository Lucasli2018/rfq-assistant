# RFQ 智能报价助手

面向外贸 / 国际站（Alibaba.com、Made-in-China、Global Sources 等）卖家的**零依赖单文件工具**。把买家的每条 RFQ 询盘，变成又快又准的报价。双击 `index.html` 即可使用，数据全部保存在本机浏览器 localStorage，无需后端、无需联网。

## 功能

- **工作台**：待处理询盘、高价值机会、报价总额、赢单率等概览 + 快捷入口
- **RFQ 智能匹配**：基于产品库对每个询盘加权打分（0-100），给出最佳匹配产品与打分理由
  - 评分维度：关键词命中(40) + 品类相符(15) + 数量满足 MOQ(15) + 目标价空间(20) + 认证匹配(10)
  - 中英文双语分词（中文二元切分 + 英文词切分）
- **报价计算器**：一次算出 EXW 出厂价 / FOB 离岸价 / CIF 到岸价
  - 成本、包装、国内运费、国际运费、保险费率、平台佣金、汇率、利润率全参数可调
  - 利润反推分析 + 买家目标价差距提示 + 三档阶梯报价建议（量大价优）
- **报价话术生成**：内置多场景多语言模板（英文报价/中文报价/跟进催单/还价应对/首次开发）
  - `{{变量}}` 占位符自动替换，可从 RFQ 一键带入买家与产品信息
  - 支持复制、保存记录、导出 .txt
- **买家分析看板**：国家分布、状态漏斗、品类热度、高价值买家榜
- **产品库 / 设置 / 数据管理**：SKU 维护、报价参数、模板增删改、导入导出备份、示例数据

## 使用

1. 双击 `index.html` 用浏览器打开（推荐 Chrome / Edge）
2. 首次打开自动载入 6 条示例 RFQ + 6 个产品，可直接体验
3. 「产品库 / 设置」页维护自己的产品与报价参数
4. 「数据管理」页导出 JSON 备份，换设备时导入

## 技术说明

- 单文件 `index.html`：内联全部 CSS / JS，零依赖、零构建
- 存储前缀 `rfq_`，localStorage 持久化
- 视觉沿用珊瑚橙主题（与 `all-in-one-workbench` 一致），响应式：桌面左侧导航 / 移动底部导航
- 已通过 Node 语法校验 + 无头 Chrome 12 项功能冒烟测试
